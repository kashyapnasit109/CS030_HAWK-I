# backend

Hawk-I REST API server built with Node.js, Express, and TypeScript.

## Getting Started

```bash
npm install
npm run dev    # → http://localhost:3001
```

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/health` | Health check |
